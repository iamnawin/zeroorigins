# ZO-POL-003 — IP and Work Product Policy

**ID:** ZO-POL-003  
**Department:** Legal & Compliance  
**Version:** 1.0  
**Owner:** Founder  
**Effective Date:** May 2026  

---

## 1. Purpose

Define ownership of intellectual property (IP) created during ZeroOrigins projects — both for client work and internal products.

---

## 2. ZeroOrigins-Owned IP

The following always belong to ZeroOrigins, regardless of who helped build them:

- All n8n workflow templates, blueprints, and reusable automation logic
- All AI system prompts, embedding logic, and scoring algorithms
- All digital products (templates, kits, guides) sold via Gumroad or other channels
- Internal tools, dashboards, and utilities built for ZeroOrigins operations
- Brand assets: logos, visual systems, tone-of-voice guidelines
- Content: LinkedIn posts, newsletters, videos, course materials
- The ZeroOrigins OS itself (this folder and its documents)

ZeroOrigins IP is **not transferred to clients** unless explicitly agreed in writing.

---

## 3. Client-Owned IP (Deliverable Work)

When a client pays for a custom project, they receive ownership of:
- The specific n8n workflow built for them (exported JSON)
- Any custom code written exclusively for their use case
- Any data, copy, or creative assets they provided as inputs

They do **not** receive ownership of:
- The underlying methodology or architecture patterns
- Any reusable modules ZeroOrigins uses across multiple client projects
- AI prompts embedded in workflows (these are ZeroOrigins IP)

The Project Agreement (ZO-TMPL-003) must define IP transfer clearly for each project.

---

## 4. Contractor Work Product

Any work created by a ZeroOrigins contractor is owned by ZeroOrigins, not the contractor, unless explicitly agreed otherwise in the contractor agreement.

Contractors must:
- Assign all work product created for ZeroOrigins to ZeroOrigins upon completion
- Not reuse or repurpose ZeroOrigins client deliverables for other clients
- Sign the NDA (ZO-TMPL-004) before starting work

---

## 5. Use of AI-Generated Content

ZeroOrigins uses AI tools (Claude, ChatGPT, Midjourney, etc.) extensively. The following rules apply:

- AI-generated content created using ZeroOrigins prompts and workflows is treated as ZeroOrigins work product.
- Do not train third-party AI models on client data without explicit written consent.
- Disclose AI usage in client deliverables if requested — do not misrepresent AI output as entirely human-created.

---

## 6. Open Source Use

When using open-source libraries or tools in client projects:
- Verify the license permits commercial use
- Do not use GPL-licensed code in proprietary client deliverables without legal review
- MIT, Apache 2.0, and BSD licenses are generally safe — confirm with each project
- Document any open-source dependencies in the project delivery notes

---

## 7. Disputes

IP disputes with clients should be handled in accordance with the Project Agreement's dispute resolution clause. Escalate to legal counsel if not resolved within 14 days of the dispute being raised.
