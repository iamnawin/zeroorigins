# ZeroOrigins Company OS

**ZeroOrigins** is an AI Systems & Automation Lab building AI-native products, agentic workflows, automation systems, digital templates, and creative technology infrastructure.

This folder is the **ZeroOrigins Operating System** — the single source of truth for how the company runs, delivers, and grows.

---

## What This Is

A practical, founder-operated company handbook. Not theory. Not corporate templates. Actual SOPs, trackers, policies, and templates that ZeroOrigins uses to run every day.

## How to Use This OS

1. Read `START_HERE.md` first — it tells you what to do in your first 30 days.
2. Use `INDEX.md` to find any specific SOP or document.
3. Every SOP has an ID (e.g., ZO-COMP-001). Reference SOPs by ID in Notion, Slack, or email.
4. Templates in `09_Templates/` are ready to use — just fill in the blanks.
5. Trackers in `10_Trackers/` should be copied to Google Sheets for live use.

---

## SOP Naming Convention

`ZO-[DEPT]-[NUMBER]_[SOP_Name].md`

Example: `ZO-SALES-003_Proposal_Creation_SOP.md`

## Maintenance

- Review all SOPs quarterly.
- Archive outdated files to `12_Archive/`.
- Update `INDEX.md` when new files are added.
