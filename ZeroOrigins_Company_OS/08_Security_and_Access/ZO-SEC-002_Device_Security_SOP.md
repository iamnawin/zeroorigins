# ZO-SEC-002 — Device Security SOP

---

## 1. Purpose

To protect ZeroOrigins data and client data from device theft, loss, or compromise.

---

## 2. Scope

All devices used for ZeroOrigins work: laptops, phones, tablets.

---

## 3. Owner

Founder

---

## 4. Trigger

When setting up any new device; review quarterly.

---

## 5. Laptop Security Checklist

- [ ] Full-disk encryption enabled (BitLocker on Windows, FileVault on Mac)
- [ ] Strong login password set (not PIN only)
- [ ] Screen auto-lock after 2 minutes of inactivity
- [ ] OS and software updates set to automatic
- [ ] Antivirus/endpoint protection installed (Windows Defender is sufficient on Windows)
- [ ] Do not install pirated software — common vector for malware
- [ ] VPN available for use on public Wi-Fi (ProtonVPN free tier is sufficient)

---

## 6. Phone Security Checklist

- [ ] Screen lock with PIN/biometric enabled
- [ ] Auto-lock after 1 minute
- [ ] 2FA authenticator app installed
- [ ] Do not jailbreak/root the device
- [ ] Find My Device / Find My iPhone enabled

---

## 7. Browser Security

- [ ] Use Chrome or Firefox with a separate profile for work
- [ ] Clear cookies on public/shared computers immediately after use
- [ ] Never save passwords in browser — use password manager extension instead
- [ ] Ad blocker installed (uBlock Origin — free and effective)

---

## 8. Network Security

- [ ] Home Wi-Fi uses WPA2 or WPA3 encryption
- [ ] Router default password changed
- [ ] Use VPN on any public Wi-Fi (cafes, airports, client offices)
- [ ] Do not work with client data on public Wi-Fi without VPN

---

## 9. What to Do if a Device is Lost or Stolen

1. Remotely wipe the device immediately (Find My / Android Device Manager)
2. Change passwords for all accounts accessed on that device
3. Revoke sessions on all critical accounts (Google, GitHub, AWS, payment tools)
4. If client data was on the device: notify the client within 24 hours
5. File a police complaint if the device had sensitive data (for insurance and compliance)

---

## 10. Quality Checklist

- [ ] Laptop encryption enabled
- [ ] Screen auto-lock at 2 minutes
- [ ] VPN installed and ready for use
- [ ] Remote wipe capability enabled on all devices
- [ ] Quarterly: review which accounts are logged in on which devices

---

## 11. Approval Required

None — Founder manages directly.

---

## 12. Output

- All devices meeting security baseline
- Remote wipe tested on each device

---

## 13. Storage Location

N/A — device configuration; no document needed.

---

## 14. Risks / Mistakes to Avoid

- **No disk encryption** — a stolen laptop without encryption gives anyone instant access to all files
- **Reusing work accounts on personal devices without lock screen** — family members or children can accidentally trigger data exposure

---

## 15. Review Frequency

Quarterly; immediately after adding any new device.
