## Purpose

## Sheet: Content Calendar

### Columns

| Column | Description | Values / Format |
|--------|-------------|-----------------|
| Content ID | Unique content reference | ZO-CONT-2026-001 |
| Publish Date | Planned or actual publish date | DD-MM-YYYY |
| Platform | Where it will be published | LinkedIn / Instagram / Twitter/X / YouTube / Newsletter / Gumroad / Website |
| Vertical | Which brand vertical | ZeroOrigins / AIwithNoBrain / EpicsToYou / IgnAIte |
| Format | Content type | Post / Carousel / Video / Reel / Newsletter / Blog / Thread / Story |
| Topic / Hook | Working title or hook line | Text |
| Goal | What this content is meant to achieve | Awareness / Lead Gen / Engagement / Product Promo / Trust Building |
| Status | Content production status | Idea / Drafting / Reviewing / Scheduled / Published / Skipped |
| Written By | Who is writing it | Naveen / AI-assisted / [Team Member] |
| Visuals | Are visuals needed? | Yes / No / Repurpose |
| Visual Status | Status of any graphic or video | Pending / In Progress / Done / NA |
| CTA | Call to action included | Book a Call / Download / Reply / Follow / Buy / None |
| Published URL | Link to live post (once published) | URL |
| Engagement Notes | Performance notes after publishing | Text |

## Weekly Content Rhythm (Recommended)

| Day | Activity |
|-----|----------|
| Monday | Plan the week's content in this tracker |

| Friday | Schedule next week's posts |
| Daily | Engage with comments and DMs |

---

## Content Pillars

Use these to maintain consistency across all ZeroOrigins content:

1. **Education** — teach something useful about AI, automation, n8n
2. **Proof** — show client results, before/after, case studies
3. **Behind the Scenes** — building the company, what Naveen is working on
4. **Offer** — direct promotion of a service, product, or booking link
5. **Opinion** — take a stance on AI trends, tools, or the industry

Target mix per week: 2 Education, 1 Proof, 1 Behind the Scenes, 1 Offer/Opinion.
