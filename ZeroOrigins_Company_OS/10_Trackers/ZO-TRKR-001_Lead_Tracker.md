## Purpose

Track every inbound and outbound lead from first contact to closed/lost. Copy this structure into Google Sheets for live use.

---

## Sheet: Lead Tracker

### Columns

| Column | Description | Values / Format |
|--------|-------------|-----------------|
| Lead ID | Auto-incremented ID | ZO-LEAD-001, 002... |
| Date Added | Date lead was captured | DD-MM-YYYY |
| Lead Name | Full name of contact | Text |
| Company | Company name (if B2B) | Text |
| Source | Where lead came from | LinkedIn / Referral / Website / Cold Outreach / Event / Other |
| Country | Lead's country | India / USA / UAE / AUS / Other |
| Service Interest | What they want | LeadFlow Setup / Custom Automation / Product Build / Digital Product / Training / Unknown |
| Budget Indicated | Rough budget if shared | Rs / USD amount or "Not Shared" |
| Stage | Current pipeline stage | New → Contacted → Discovery Scheduled → Discovery Done → Proposal Sent → Negotiation → Won → Lost → Nurture |
| Discovery Call Date | Date call was scheduled or completed | DD-MM-YYYY |
| Proposal Sent Date | Date proposal was sent | DD-MM-YYYY |
| Follow-up Date | Next follow-up due | DD-MM-YYYY |
| Decision Date | Date they said yes/no | DD-MM-YYYY |
| Deal Value | Agreed contract value | Rs / USD amount |
| Notes | Key context, objections, preferences | Text |
| Owner | Who is managing this lead | Naveen / [Team Member] |

---

## Stage Definitions

| Stage | Meaning |
|-------|---------|
| New | Lead identified, not yet contacted |
| Contacted | First message sent (LinkedIn DM, email, WhatsApp) |
| Discovery Scheduled | Call booked |
| Discovery Done | Call completed, notes captured |
| Proposal Sent | Proposal document shared |
| Negotiation | Back-and-forth on scope or price |
| Won | Contract signed / payment received |
| Lost | Declined, ghosted, or budget mismatch |
| Nurture | Not ready now — follow up in 30–90 days |

---

## Weekly Review Checklist

- [ ] Are all new leads from this week added?
- [ ] Are follow-up dates current?
- [ ] Any leads stuck in a stage for 7+ days without action?
- [ ] Any Won deals without invoices raised?
- [ ] Any Lost deals — capture the reason in Notes

---

## Source Tracking

Use consistent source labels for reporting:
- **LinkedIn** — organic DM or connection
- **Referral** — introduced by an existing client or contact
- **Website** — inbound via contact form or CTA
- **Cold Outreach** — proactive email or DM campaign
- **Event** — met at webinar, meetup, or conference
- **Gumroad** — digital product buyer who enquired about services
- **Other** — anything that doesn't fit above
