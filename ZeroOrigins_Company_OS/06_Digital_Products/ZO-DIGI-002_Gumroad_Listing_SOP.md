## 5. Gumroad Listing Structure

A Gumroad listing has 5 visible sections. Each must be done correctly:

| Section | What to Put There |
|---------|-------------------|
| Product Name | Clear, specific outcome-first name |
| Tagline | 1 sentence: who it's for + what it does |
| Description | Full copy (see template below) |
| Cover Image | 1200x630px thumbnail (see Section 9) |
| Price | Set per ZO-DIGI-003 pricing SOP |

---

## 6. Product Naming Formula

`[Who] — [Outcome] [Format]`

Examples:
- `Founders — n8n Automation Starter Pack`
- `Solo Consultants — Lead Follow-Up System`
- `AI Builders — 50 Claude Prompts That Actually Work`

Do NOT use vague names like "AI Toolkit" or "Automation Template" with no context.

## 8. Gumroad Settings Checklist

Go through these settings before publishing:

- [ ] **URL slug** — short and readable: `gumroad.com/l/leadflow-starter`
- [ ] **Refund policy** — set to "30-day refund if you can show you tried it" (reduces chargebacks)
- [ ] **File uploaded** — correct version, file opens without errors
- [ ] **Receipt message** — customized (not generic Gumroad default)
- [ ] **Summary field** — 1 sentence for Gumroad marketplace SEO
- [ ] **Tags** — add 3–5 relevant tags (e.g., n8n, automation, lead generation)
- [ ] **Category** — correct category selected

---

## 9. Cover Image (Thumbnail) Requirements

The thumbnail is the most important conversion element — it's the first thing seen in feeds.

**Specs:**
- Size: 1200 × 630px (minimum)
- Format: PNG or JPG
- File size: under 2MB

**Design formula:**
```
[Large, bold product name — 3 words max]
[Short supporting line — what they get]
[Brand mark — "ZeroOrigins" in corner]
[Simple background — solid color or gradient]
```

**Thumbnail don'ts:**
- No stock photos of laptops or handshakes
- No cluttered text (if someone needs to squint, redo it)
- No dark text on dark background
- No generic "AI" imagery that looks like every other product

**Tools:** Canva (use 1200x630 template), Figma, or Adobe Express.

## 15. Risks / Mistakes to Avoid

- **Launching without a thumbnail** — Gumroad shows a blank grey box; looks unprofessional and kills conversions
- **Generic description** — "This template helps you automate things" tells the buyer nothing; be specific about the outcome
- **Skipping the "Not for you" section** — this section builds trust; buyers who aren't a fit self-select out before purchase (fewer refunds)
- **Wrong URL slug** — Gumroad auto-generates ugly slugs; always set a clean one before publishing
- **No receipt customization** — the default Gumroad receipt says "Thank you for your purchase" and nothing else; add your welcome message there

---
