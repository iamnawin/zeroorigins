# Required Tools — ZeroOrigins Workflow Starter Kit

Everything listed here has a free tier. You do not need to pay for any tool to run this starter kit.

---

## Core Tools

### n8n (Automation Engine)
- **What it does:** Runs your workflows — processes form submissions, sends emails, updates your sheet
- **Get it:** https://n8n.io
- **Which plan:** Free cloud trial, or self-host for free on any server
- **Notes:** If you self-host, you need a server with Node.js. n8n Cloud is easiest to start.

### Google Sheets (Lead Tracker)
- **What it does:** Stores every lead that comes through your form
- **Get it:** sheets.google.com (free with any Google account)
- **Notes:** One sheet is all you need. Do not delete or rearrange the column headers after setup.

### Gmail (Email Sending)
- **What it does:** Sends confirmation emails to leads and notification emails to you
- **Get it:** Free with any Google account
- **Notes:** n8n connects to Gmail via OAuth — you authorise it once and it works automatically.

## Form Tool (Choose One)

| Tool | Free tier | Webhook support | Notes |
|---|---|---|---|
| Tally | Yes | Yes (free) | Recommended — easiest webhook setup |
| Typeform | Limited | Yes (paid) | Cleaner UI, but webhook requires paid plan |
| Google Forms | Yes | Via Apps Script | More setup required |
| Webflow forms | Yes | Yes | Good if your site is on Webflow |
| Carrd | Yes | Yes (Pro) | If using Carrd for your landing page |

**Recommended:** [Tally.so](https://tally.so) — free, simple, and webhook is built in on the free plan.
