==============================================================

These are example JSON payloads to POST to each webhook endpoint.
Use these to test your workflows before connecting real forms.

You can test with cURL, Postman, or Insomnia.

--------------------------------------------------------------
HOW TO TEST WITH CURL
--------------------------------------------------------------

Replace YOUR_WEBHOOK_URL with your actual n8n webhook URL.

  curl -X POST https://YOUR_WEBHOOK_URL/webhook/qualify-lead \
    -H "Content-Type: application/json" \
    -d '{"name":"Test User","email":"test@example.com","business":"Test Co","message":"I need help automating my lead follow-up","source":"Direct"}'

--------------------------------------------------------------
HOW TO TEST IN POSTMAN / INSOMNIA
--------------------------------------------------------------

1. Create a new POST request
2. Set URL to your webhook endpoint
3. Set Body type to: JSON (application/json)
4. Paste the example payload above
5. Click Send

You should see a 200 response with a JSON body confirming receipt.
Check your n8n Executions tab to see the full workflow run.

--------------------------------------------------------------
FIELD MAPPING REFERENCE
--------------------------------------------------------------

The workflows accept flexible field names. These are equivalent:

  name / full_name           → lead's full name
  email                      → lead's email (required)
  business / company         → company name
  message / notes            → lead's message
  source / utm_source        → where they came from
  time_slot / time           → preferred meeting time (HH:MM)
  date                       → preferred meeting date (YYYY-MM-DD)
  urgency                    → critical / high / normal (alerts only)
