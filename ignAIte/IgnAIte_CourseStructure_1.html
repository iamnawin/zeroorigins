Agent Patterns You'll Build
🔁 ReAct Agent
Reason → Act → Observe loop. Agent thinks step-by-step, calls tools, observes output, adjusts. Foundation of all agentic systems.
👥 Multi-Agent Supervisor
One supervisor agent delegates to specialist sub-agents (researcher, coder, writer). Each does one thing perfectly.
📚 RAG Pipeline
Retrieval Augmented Generation — embed your docs into a vector DB, retrieve relevant chunks, feed to LLM for grounded answers.
🛠️ Tool-Calling Agent
Agent with access to tools (search, code exec, DB, API). Decides which tool to call, when, with what params — autonomously.
🌐 MCP Server + Client
Build your own MCP server exposing tools/resources. Connect any LLM client (Claude, Cursor, custom) to your backend via standard protocol.
🔗 A2A Agent Network
Multiple agents publishing Agent Cards, discovering each other, delegating tasks peer-to-peer without a central orchestrator.
