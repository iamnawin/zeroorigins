# Client Onboarding Checklist

*Use this every time a new project starts.*
*Run through it in order. Check off each item before moving to the next.*
*A strong start makes every project easier from here.*

---

## PHASE 0 — BEFORE THE DEAL CLOSES

These happen during the sales process, not after.

- [ ] Ran a discovery call using the Client Discovery Questions template
- [ ] Sent a personalized proposal (using Proposal Template)
- [ ] Attached the Scope of Work document
- [ ] Received written confirmation (email) that the client has reviewed and accepted scope
- [ ] Received signed service agreement or written email approval
- [ ] Received deposit payment

**Gate:** Do NOT start work until deposit is received and scope is confirmed in writing.

---

## PHASE 1 — PROJECT SETUP (Day 1)

- [ ] Sent Project Kickoff document to client
- [ ] Received client confirmation of Kickoff document
- [ ] Created project folder (local and/or cloud: [Google Drive / Notion / Trello])
- [ ] Set up a project management space for this client: [TOOL NAME]
- [ ] Scheduled the kickoff call (if applicable)
- [ ] Added project start and end dates to your calendar
- [ ] Set reminder for follow-up / first milestone check-in
- [ ] Sent invoice for deposit (if not yet paid)

---

## PHASE 2 — ASSET COLLECTION (Days 1–3)

- [ ] Sent client the asset request list (included in Kickoff document)
- [ ] Received brand assets: Logo (SVG/PNG), colors, fonts
- [ ] Received content / copy from client (if required)
- [ ] Received access credentials (website, platform, tools, ad accounts)
- [ ] Received any reference materials, mood boards, or competitor examples
- [ ] Confirmed all logins work and access is at the right permission level
- [ ] Backed up any existing assets before making changes
- [ ] All assets organized in your project folder

**If assets are delayed:** Send a polite follow-up after 2 business days:
> "Just checking in — I'm waiting on the [assets] before I can begin.
> Can you send those over by [DATE]? Happy to help if you need anything clarified."

---

## PHASE 3 — PROJECT KICKOFF (Days 1–5)

- [ ] Set up internal project timeline (with buffer dates)
- [ ] Created internal checklist of tasks by phase
- [ ] Reviewed scope document one more time — confirm you know exactly what's in and out
- [ ] Set up communication channel with client (confirm: email, Slack, WhatsApp, etc.)
- [ ] Sent first "we've officially started" message to client:
  > "All set on our end — kicking off [PROJECT NAME] today.
  > First update coming your way on [DATE]."
- [ ] Saved scope document in client's project folder for reference

---

## PHASE 4 — DURING THE PROJECT

*(Check these throughout — not just at the start)*

- [ ] Sending progress updates per agreed frequency
- [ ] Staying within the agreed scope — flag any scope creep immediately
- [ ] Tracking hours / work log (if hourly or for reference)
- [ ] Delivering review drafts on time
- [ ] Requesting feedback clearly: "Please review X and send feedback by [DATE]"
- [ ] Logging any changes or decisions made in writing (email trail)
- [ ] Issuing change orders before implementing any out-of-scope requests

---

## PHASE 5 — REVIEW ROUNDS

For each deliverable:

- [ ] Sent draft with a clear prompt: "Here's [DELIVERABLE]. Please review and send consolidated feedback by [DATE]."
- [ ] Received feedback (consolidated, from single point of contact)
- [ ] Implemented revisions within agreed turnaround time
- [ ] Confirmed which revision round this is (track against the included rounds)
- [ ] Received written approval for each deliverable before moving on

**After the included revision rounds are used:**
- [ ] Issued change order if additional rounds needed
- [ ] Received written approval of change order before proceeding

---

## PHASE 6 — FINAL DELIVERY

- [ ] All deliverables complete and internally quality-checked
- [ ] Files organized and labeled properly (no "FINAL_v3_FINAL_USE_THIS.pdf")
- [ ] Delivery package assembled (all files in one place)
- [ ] Delivery method confirmed with client (Drive link, direct upload, hand-off call)
- [ ] Walkthrough call scheduled (if included)
- [ ] Handoff document prepared (what was built, how to use/maintain it)
- [ ] Final invoice sent
- [ ] Delivered files ONLY after final payment received (or after payment is confirmed incoming)

---

## PHASE 7 — POST-DELIVERY (Week 1 After Handoff)

- [ ] Sent a brief check-in 3–5 days after delivery:
  > "Hey [NAME], just checking in — is everything working as expected?
  > Let me know if you have any questions."
- [ ] Resolved any minor issues within the post-launch support window
- [ ] Asked for a testimonial or case study (once they're happy):
  > "If the project met your expectations, I'd really appreciate a short testimonial.
  > Would you be open to writing 2–3 sentences about working together?"
- [ ] Added project to your portfolio/case study notes
- [ ] Filed all project documents in your archive folder
- [ ] Sent offboarding message explaining what retainer/ongoing support looks like

---

## PHASE 8 — RELATIONSHIP MAINTENANCE

*(30, 60, 90 days post-project)*

- [ ] 30-day check-in sent (casual, no pitch): "How's [PROJECT OUTCOME] working out?"
- [ ] 60-day check-in with value add (relevant tip, article, or observation)
- [ ] 90-day check-in with soft offer: "If you're ready for the next phase, I'd love to discuss it."

*Repeat clients cost zero to acquire. Stay in touch.*
